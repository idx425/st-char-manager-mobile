# 角色卡管理 · Mobile (st-char-manager-mobile)

SillyTavern 角色卡管理扩展的手机优化版。功能与 [st-char-manager](https://github.com/idx425/st-char-manager) 同步，额外针对触屏与窄屏：

- 修复手机标签栏/文件夹栏无法左右划动的问题
- 顶部快捷栏支持折叠，解决卡片位置靠下、无法向上划看全内容的问题
- 修复重启酒馆后创建的文件夹消失问题
- 修复取消接管原生角色面板后面板变到顶上只露半截的问题
- 支持 **紧凑模式 (Compact)**：调小卡片与字号间距，适合小屏手机
- 支持 **浅色/暗色主题** 自由切换

## 更新日志

### v4.5.1
- **对照 ST 酒馆（SillyTavern release）与 TT 酒馆（TauriTavern，前端同步 1.18.0）源码全面审计后的修复版**
- **修复「删除的标签重启后复活」**：删除标签/移除卡内嵌标签时，通过 `/api/characters/merge-attributes`（ST 后端 deepMerge 对数组整体替换语义）把剥离后的 tags 数组写回卡片文件；即使写回失败，也有本地屏蔽名单兜底，重启后不再被自动同步复活
- **修复标签同步性能问题**：卡内嵌标签 → 全局标签的注册改为节流批量同步（管理器打开时执行），不再在网格渲染热路径里逐卡写设置
- **修复删卡残留**：删除角色卡后同步清理 tagMap 挂载与按卡屏蔽名单（对齐 ST 原生 `delete tag_map[avatar]` 行为）
- **修复 WEBP 导入必失败**：当前 ST/TT 后端导入器均不支持 webp（仅 png/json/charx/byaf/yaml），现给出明确提示并把文件选择器改为 `.png .json .charx .byaf .yaml .yml`（新增 BYAF 支持）
- **修复上一版误将卡片网格改为 3 列的问题**：手机卡片网格恢复 2 列设计，仅快捷工具栏为 3 列（<500px）/ 4 列（≥500px），折叠/展开按钮独占一整行
- **通用端去除重量级 DOM 观察器**：通用端只注入纯 CSS 的快捷栏布局（无 MutationObserver），避免桌面端被手机布局钉死
- 手动重新创建同名标签会自动解除屏蔽


### v3.2.1
- **全面修复浅色模式 (Light Mode) 视觉与可读性 Bug**：彻底重构浅色/深色主题 CSS 优先级体系，修复浅色模式下分页栏文字重叠/隐形、搜索框背景变黑、快捷栏与文件夹栏颜色与字体对比度不足等缺陷。
- **全端适配与高对比度增强**：通用端与手机端统一覆盖，弹窗标题、关闭按钮、各种状态 Chip 与分类标签在浅色与深色主题下均保持高清晰度与无障碍对比度。

### v3.2.0
- **修复标签栏/文件夹栏左右滑动**：重构触屏 `overflow-x: auto` 与 `-webkit-overflow-scrolling: touch`，顺畅横划
- **快捷工具栏一键折叠**：点顶部 `chevron-up` 图标可将快捷按钮折叠成一行，让角色卡网格立即升到顶部
- **修复文件夹重启丢失 bug**：修复启动初始化异步导致的脏数据擦除问题，创建文件夹立即写盘
- **修复取消接管侧边栏变形**：取消勾选接管原生角色面板后，完全还原原生面板样式与定位
- **新增紧凑模式**：点顶部或设置中的「紧凑模式」缩小间距，小屏手机一屏能看更多卡
- **新增浅色明亮主题**：适合浅色背景或白日模式用户
