# 角色卡管理 · Mobile (st-char-manager-mobile)

SillyTavern 角色卡管理扩展的手机优化版。功能与 [st-char-manager](https://github.com/idx425/st-char-manager) 同步，额外针对触屏与窄屏：

- 修复手机标签栏/文件夹栏无法左右划动的问题
- 顶部快捷栏支持折叠，解决卡片位置靠下、无法向上划看全内容的问题
- 修复重启酒馆后创建的文件夹消失问题
- 修复取消接管原生角色面板后面板变到顶上只露半截的问题
- 支持 **紧凑模式 (Compact)**：调小卡片与字号间距，适合小屏手机
- 支持 **浅色/暗色主题** 自由切换

## 更新日志

### v3.2.0
- **修复标签栏/文件夹栏左右滑动**：重构触屏 `overflow-x: auto` 与 `-webkit-overflow-scrolling: touch`，顺畅横划
- **快捷工具栏一键折叠**：点顶部 `chevron-up` 图标可将快捷按钮折叠成一行，让角色卡网格立即升到顶部
- **修复文件夹重启丢失 bug**：修复启动初始化异步导致的脏数据擦除问题，创建文件夹立即写盘
- **修复取消接管侧边栏变形**：取消勾选接管原生角色面板后，完全还原原生面板样式与定位
- **新增紧凑模式**：点顶部或设置中的「紧凑模式」缩小间距，小屏手机一屏能看更多卡
- **新增浅色明亮主题**：适合浅色背景或白日模式用户
